# Universal Dev Team — Antigravity IDE + UTE Profile

Skill de equipo virtual orientada a bajo consumo de contexto y memoria persistente.

## Instalación

Copiar `universal-dev-team/` como:

`.agents/skills/universal-dev-team/`

## Diseño

Universal por defecto. El perfil `references/ute-profile.md` solo se carga para proyectos UTE/Laravel/Firebird/MySQL.

## Memoria

La skill usa `memory/` en la raíz del proyecto. `resources/` contiene plantillas iniciales.

## Modos

MICRO → STANDARD → DEEP. El Lead escala solo cuando la evidencia lo exige.
