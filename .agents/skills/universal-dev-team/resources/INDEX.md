# Memory Index

Actualiza este archivo solo cuando cambien los documentos o aparezca conocimiento que deba recuperarse con frecuencia. Si supera ~150 líneas, poda otro archivo en vez de agregar más aquí.

- PROJECT.md — stack, arquitectura, bases de datos/integraciones. Completar en la primera tarea real (ver SKILL.md, "Arranque en un proyecto nuevo").
- DECISIONS.md — decisiones técnicas con fecha. No se borra; decisiones superadas se marcan como reemplazadas.
- TASK_STATE.md — tarea activa únicamente (se resetea al cerrar).
- KNOWN_ISSUES.md — problemas conocidos. Se condensan a una línea 5 tareas después de resueltos.
- CONVENTIONS.md — convenciones reales confirmadas en el repo (nunca inventadas).
- SECURITY_NOTES.md — hallazgos y deuda técnica de seguridad. Nunca contiene secretos reales.
- DB_SCHEMA_NOTES.md — mapa de entidades/relaciones no obvias y particularidades de la base de datos.
